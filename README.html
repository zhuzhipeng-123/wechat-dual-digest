微信文章，沿两条轨道抵达。

本机运行的练习与招聘双日报工具。它从一个明确配置的订阅源发现候选，再用微信原文核对身份和时间，保存正文与图片，最后生成本地报告或通过邮件送达。

练习：原文与可用图片
招聘：证据、岗位与评级

两个真实来源适配器完成，订阅地址待配置验收
真实邮件送达默认关闭，尚未发信

现在能做什么

ACTUAL CAPABILITIES

源码保持为少量职责文件：核心规则、来源处理、流水线、报告、调度、邮件交付、招聘分析、Agnes 和入口。只增加了职责独立的邮件模块，没有引入 Web 服务、任务队列或插件框架。

单一来源每个账号绑定一个由环境变量提供的 RSS/Atom 地址；Feed 只给候选，原文身份、标题和发布时间才是收录依据。
完整原文正文经过白名单清理，图片流式限额下载并留在原位置；练习缺关键图会等待补收，招聘仍保留可读原文。
运行保障SQLite 原子认领、稳定文章键、有限迟到补收、同一 run_id、完整版本清单和单一固定入口。
一个交付渠道SMTP 默认关闭；邮件使用 CID 内嵌本地图片。明确失败可只重发报告，结果不确定不会自动重发。
真实限制：代码已能消费 RSS/Atom，但本机尚未配置“国聘”和“我爱学逻辑”的真实 Feed，也没有验证其多篇覆盖和发现延迟。真实邮箱没有被使用；真实定时送达、真实双日报、招聘图片 OCR 与文章抽取仍待人工验收。离线通过不等于公众号订阅或收件已通过。

安装

WINDOWS · PYTHON 3.12
  1. 在项目目录创建隔离环境。
    py -3.12 -m venv .venv
  2. 安装锁定依赖。首次安装包含本地 OCR 运行时，耗时会更长。
    .venv\Scripts\python.exe -m pip install -r requirements.lock
  3. 复制配置样例，只在本机填写公众号、来源绑定和时间。
    Copy-Item config\accounts.example.toml config\accounts.toml Copy-Item config\settings.example.toml config\settings.toml
  4. 把两个真实订阅地址放进环境变量。含 Token 的完整地址不会写入 SQLite、报告或日志。
    $env:PRACTICE_FEED_URL = "https://你的来源/练习.xml" $env:RECRUITMENT_FEED_URL = "https://你的来源/招聘.xml"
  5. 邮件默认关闭。需要时先在 config/settings.toml 启用，再设置发件人、收件人、账号和密码环境变量；不要把密码写进 TOML。

运行与检查

ONE LOCAL ENTRY

双击 start.cmd，或在终端运行：

.venv\Scripts\python.exe -m app.cli

先检查配置，再做隔离预览；只有配置完整时调度入口才会启动：

.venv\Scripts\python.exe -m app.cli check .venv\Scripts\python.exe -m app.cli preview --kind both .venv\Scripts\python.exe -m app.cli schedule

邮件明确失败后，只重发已有完整报告；不会重新发现、下载、OCR 或调用模型：

.venv\Scripts\python.exe -m app.cli retry-send <run_id>

旧进程确认停止且运行目录有完整清单时，可显式恢复记录：

.venv\Scripts\python.exe -m app.cli recover-report <run_id> --confirm-stopped

开发验证

.venv\Scripts\python.exe -m pytest -ra .venv\Scripts\ruff.exe check app tests .venv\Scripts\python.exe -m compileall -q app tests

合成样例位于 samples/preview/，页面上明确写明不是微信、真实订阅、SMTP 或 Agnes 实测。

数据边界

LOCAL BY DEFAULT
  • data/：浏览器会话、临时资源、证据、OCR 文本和 SQLite 运行账本；不进 Git。
  • output/preview/<run_id>/：手动预览；不认领或覆盖正式任务。
  • output/YYYY-MM-DD/：正式固定入口；每次先完成不可变运行版本再替换入口。
  • Agnes 仅接收本篇必要来源字段、正文纯文本、OCR 文本和证据 ID；不发送图片、Cookie、Key 或绝对路径。

程序与电脑必须保持运行，定时任务才会继续。可选择“当天错过后补跑一次”，但已领取或失败的任务不会自动重跑；项目也不会擅自注册开机启动。

第一版只消费一个外部 RSS/Atom 来源，不建设 RSS 平台。MCP、Markdown 导出、FastAPI、网页后台、多渠道和通用文章平台均不在范围内。
