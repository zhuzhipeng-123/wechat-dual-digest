Local dispatch / first MVP

微信文章，沿两条轨道抵达。

本机运行的练习与招聘双日报工具。它把搜索、原文核时、证据、分析和发布拆开记录，让失败可见，也让“未发现”和“没有发文”保持不同。

练习：原文与可用图片
招聘：证据、岗位与评级
离线核心25 项测试通过
微信读书会话验收浏览器已登录；应用专用会话未建立
真实双日报尚未验证

现在能做什么

ACTUAL CAPABILITIES

源码刻意保持为 8 个职责文件：核心规则、来源处理、Agnes、招聘分析、流水线、报告、调度和入口。小概念直接放回所属流程，避免为了“架构完整”增加跳转。

共同入口解析账号与时间配置，冻结 86400 秒窗口，区分发现、抓取、分析与发布状态。
练习轨按包含词与排除词筛标题，净化正文，保留安全图片；绝不运行 OCR 或模型。
招聘轨本地 OCR 包装、Agnes 固定模型协议、严格 Schema/证据引用、岗位—地点关系和代码评级。
运行保障SQLite 原子认领、跨进程去重、预览隔离、不可变运行版本与固定报告入口。
真实限制：用户提供的两篇微信原文已能由应用浏览器读取标题、公众号、精确时间和正文，但仅凭公众号名发现当天全部文章仍未通过。微信读书网页只观察到电子书搜索；搜狗微信会触发反自动化验证、遗漏新文并返回不稳定链接。调度器不会在来源未验证时生成虚假的零结果。Agnes 合成协议探针已经通过，但真实 OCR 图片、招聘文章抽取、双日报和配置分钟运行仍待验收。

安装

WINDOWS · PYTHON 3.12
  1. 在项目目录创建隔离环境。
    py -3.12 -m venv .venv
  2. 安装锁定依赖。首次安装包含本地 OCR 运行时，耗时会更长。
    .venv\Scripts\python.exe -m pip install -r requirements.lock
  3. 复制配置样例，只在本机填写公众号和时间。
    Copy-Item config\accounts.example.toml config\accounts.toml Copy-Item config\settings.example.toml config\settings.toml
  4. 如需 Agnes，在当前终端设置 Key。Key 不写入源码、报告或日志。
    $env:AGNES_API_KEY = "在本机填写"

运行与检查

ONE LOCAL ENTRY

双击 start.cmd，或在终端运行：

.venv\Scripts\python.exe -m app.cli

当前菜单可检查微信读书页面状态、生成离线合成样例和打开报告目录。真实来源适配器通过验证前，菜单会拒绝启动正式调度。

开发验证

.venv\Scripts\python.exe -m pytest -ra .venv\Scripts\ruff.exe check app tests .venv\Scripts\python.exe -m compileall -q app tests

合成样例位于 samples/preview/，页面上明确写明不是微信或 Agnes 实测。

数据边界

LOCAL BY DEFAULT
  • data/：浏览器会话、证据、OCR 文本和 SQLite 运行账本；不进 Git。
  • output/preview/<run_id>/：手动预览；不认领或覆盖正式任务。
  • output/YYYY-MM-DD/：正式固定入口；每次先完成不可变运行版本再替换入口。
  • Agnes 仅接收本篇必要来源字段、正文纯文本、OCR 文本和证据 ID；不发送图片、Cookie、Key 或绝对路径。

程序与电脑必须保持运行，定时任务才会继续。项目不会擅自注册开机启动，也不会自动重跑错过或失败的整窗任务。

第一版只服务双日报闭环。MCP、RSS、Markdown 导出、FastAPI、网页后台与通用文章平台均不在范围内。
